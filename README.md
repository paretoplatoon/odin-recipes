# odin-recipes

Complete TOP HTML Project

Goal: Create HTML structure and demonstrate skills learned in initial lessons of The Odin Project.

Demonstrate HTML Core Competencies of:

- Boilerplate <!DOCTYPE html>, etc.
- Head, Body
- Elements (anchor, images, headings, paragraphs, lists)
- Attributes (href, rel, target, width, alt, etc.)

In Practice/setup, execute with command line prompting and git.

Reference for the project: [Foundations Project - Recipes](https://www.theodinproject.com/lessons/foundations-recipes)
